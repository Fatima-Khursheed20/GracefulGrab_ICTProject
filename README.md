# GracefulGrab

A front-end e-commerce website built with HTML and CSS for an ICT course project.

## Features
- Homepage, products, and category pages (shirts, hoodies, blazers, jackets)
- Product detail and cart pages
- Login, signup, and payment pages
- Responsive styling with custom CSS

## Tech Stack
- HTML5
- CSS3

## How to Run
Open `homepage.html` in any web browser.
